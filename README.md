# 🚀 Repositório de Automações e Scripts

Bem-vindo ao meu repositório de automações! Este espaço foi centralizado para armazenar e compartilhar scripts desenvolvidos para otimizar fluxos de trabalho, eliminar tarefas repetitivas e resolver problemas do dia a dia de forma automatizada.

---

## 🛠️ Tecnologias Utilizadas

O repositório conta com soluções em diferentes ambientes e interpretadores:

*   **Batch (`.bat` / `.cmd`):** Automações rápidas e nativas para o ecossistema Windows.
*   **PowerShell (`.ps1`):** Administração avançada de sistemas, manipulação de arquivos e tarefas de infraestrutura.
*   **Python (`.py`):** Soluções multiplataforma robustas, processamento de dados e lógicas avançadas.

---

```text
📦 automacoes-e-scripts
 ┣ 📂 batch/         # Scripts em arquivo de lote (.bat)
